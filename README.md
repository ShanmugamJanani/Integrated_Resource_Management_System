**Integrated Resource Management System (IRMS)**

An integrated, enterprise-grade digital resource management platform developed as a 3rf year undergraduate group project for the Bachelor of Science (Hons) in Software Engineering at CINEC Campus.

The Integrated Resource Management System (IRMS) was engineered to resolve critical administrative and logistical requirements, as operations like resource tracking, file management, and inventory monitoring were previously handled manually. The platform unifies three core enterprise subsystems into a single cohesive, web-based application:

  1. Library Management System: Automates book cataloging, advanced search, user borrowing/returning, and automated fine calculation.
  2. File Tracking System: Digitizes document archiving, location mapping (Cupboard, Rack, Docket, and Position tracking), and docket workflows
  3. Store Inventory Management System: Oversees internal stock supplies, purchase tracking, department-wise asset issuance, and reorder alerts.

🛠️ Technology Stack

Frontend: HTML5, CSS3, JavaScript, Bootstrap 5

Backend: PHP

Database Management System: MySQL / phpMyAdmin 

Development Methodology: V-Model (Structured Verification and Validation)


📂 **Core Database Schema Summary** 

The application relies on a relational MySQL database featuring relational integrity constraints, triggers, and automated logging tables (such as deletedfiles triggered during docket removal)
